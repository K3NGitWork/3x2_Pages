Support

New to Unfold? The Guide shows how it works, with screenshots. Most questions are answered below.

Getting started

  • Unfold an archive: double-click it, drop it on the Unfold window, or right-click it in Finder and choose Unfold Here, Unfold to Folder or Unfold to….
  • Where do the files go? One item inside lands next to the archive; several get their own folder named after it. Change this in Settings › General › Opening an archive.
  • The welcome screen explains folder access. Open it again with ? in the main window or in Settings › About › Help.

Frequently asked questions

I don't see “Unfold Here” when I right-click in Finder.

Turn on Unfold's Finder extension: System Settings › General › Login Items & Extensions › Finder (under Extensions) › Unfold. The Unfold Quick Action works without it (right-click › Quick Actions).

Unfold asks for access to a folder. Why?

macOS only lets apps into folders you allow. Unfold needs the archive's folder to find the other parts of a multipart archive and to save next to it. Allowing your home folder once covers Downloads, Desktop and Documents. You can review or remove folders in Settings › General › Folder Access.

“Part 3 is missing.”

A multipart archive needs all parts in the same folder with the same name (Movie.part1.rar, Movie.part2.rar …). Download the missing part, put it next to the others and try again.

“Wrong password” although I'm sure it's right.

Passwords are case-sensitive and spaces count. Copy and paste from the source if you can. If the archive was created on Windows with special characters, try typing them again by hand.

How do saved passwords work?

Add passwords in Settings › Passwords, or tick “Remember in list” when Unfold asks. For an encrypted archive, Unfold tries the list from top to bottom before asking, and moves the one that worked to the top. The list is stored in your Keychain.

Unfold quits by itself.

That's on purpose: when started from Finder or by a double-click, Unfold shows a small progress panel and quits a few seconds after finishing. Open the main window, or turn on Settings › General › Keep Unfold open after extracting, to keep it running.

Can Unfold create archives?

No, Unfold only extracts. To create a ZIP, right-click files in Finder and choose Compress.

Is Unfold really free?

Yes, every feature, with no ads, no subscription and no in-app purchases.

Which formats are supported?

RAR (RAR 1.5 to RAR5, multipart, encrypted data and file names), ZIP (ZipCrypto and AES), 7z (including encrypted archives and .7z.001 splits), TAR with GZ, BZ2, XZ, ZST and LZ4, single compressed files, CPIO, ISO, CAB, LHA, AR/DEB and XAR. Split ZIP files (.z01 …) aren't supported yet.

Getting started

  • Unfold an archive: in Files, tap Share › Unfold Archive to unfold right there without opening the app, or tap + in Unfold.
  • Multipart sets: put all parts in the same folder in Files and open any of them.
  • Where do the files go? Next to the archive. If that folder can't be written to, they go to On My iPhone › Unfold.

Frequently asked questions

Where do the unfolded files go?

Next to the archive. If that folder can't be written to, they go to On My iPhone › Unfold (On My iPad on iPad) in the Files app.

Unfold asks for a folder. Why?

iPhone and iPad only let Unfold see the file you opened. Allow the archive's folder once, and Unfold finds every part of a multipart set and saves next to the archive. Downloads is the one most people need; add more in Settings › General › Folder Access.

“Part 3 is missing.”

A multipart archive needs all parts in the same folder in Files, with the same name (Movie.part1.rar, Movie.part2.rar …). Download the missing part, put it next to the others and open any part again.

“Wrong password” although I'm sure it's right.

No, Unfold only extracts. To create a ZIP, touch and hold files in Files and choose Compress.
